# Text Processing Scripts

## Description

This directory contains utility scripts for text processing and manipulation tasks.

## Contents

- Text filtering utilities
- String processing helpers

## Usage

The scripts in this directory are meant to be imported or used directly for text processing operations.

## Example

```python
from text_utils import filter_string

filtered = filter_string("Hello123!@#")
print(filtered)  # Output: Hello!@#
```
