# Automation with Python

A collection of self-made Python automation scripts to simplify various tasks.

## Overview

This repository contains a variety of Python scripts for automating common tasks and improving workflow efficiency. Each script is contained in its own directory with documentation and requirements.

## Scripts

### Desktop Management

- **[changedesktopthroughcursor](./changedesktopthroughcursor)**: Automatically switch between virtual desktops based on mouse cursor position.

### File Operations

- **[autotype](./autotype)**: Automatically type text from a file using keyboard shortcuts.
- **[getSizeOfAllDirectories](./getSizeOfAllDirectories)**: Calculate and display directory sizes with human-readable formatting.
- **[replaceTabwithSpace](./replaceTabwithSpace)**: Replace tab characters with spaces in text files.
- **[rmillegalname](./rmillegalname)**: Detect and fix filenames with illegal characters.
- **[syncronizeFiles](./syncronizeFiles)**: Synchronize files between directories with various options.

### Code Management

- **[removeComments](./removeComments)**: Remove comments from source code files across 30+ programming languages.

### System Tools

- **[check_runningprocess_in_bg](./check_runningprocess_in_bg)**: Detect which executable files are currently running as processes.

### AI Integration

- **[copilot_hack](./copilot_hack)**: Automate interaction with GitHub Copilot.
- **[gimini_hack](./gimini_hack)**: Generate code using Google's Gemini AI API.
- **[mission_cheat](./mission_cheat)**: Automate code editor interactions for task completion.

### Other

- **[temp](./temp)**: Temporary scripts for testing and development.
- **[text](./text)**: Text processing utility scripts.

## Installation

Each script has its own requirements.txt file if external packages are needed. To install dependencies for a specific script:

```bash
cd script_directory
pip install -r requirements.txt
```

## Usage

Navigate to the specific script's directory and check its README.md file for detailed usage instructions.
